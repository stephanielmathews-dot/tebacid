# tebacid
Tool for bacterial identification in Tiny Earth Lab
Biochemical characterization information for 30 common soil bacteria was used to create a database based on Bergey's Manual of Determinitive Microbiology. 
Key tests are: Gram stain,	Catalase,	Oxidase,	Gelatinase and	Glucose. The secondary tests are	Amylase,	Hydrogen sulfide, 	Indole,	Motility,	Lactose,	Mannitol and	Hemolysis. 
Use Google Gemini Canvas this databse was used to create a JSON file and then code for this identification tool. 

There are multiple versions available in this repository. 
Version 1 contains the html code with 30 bacteria in the JSON.
Version 2 contained images for test results.
